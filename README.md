## 🏛️ Overview | نبذة عن المشروع

Production-grade corporate web application for **Elite For Contracting (شركة إيليت للمقاولات)**, an accredited Class 1 General & MEP Contractor based in Riyadh, Saudi Arabia. Backed by over 35 years of engineering heritage and certified BIM execution.

The platform is designed with a **Luxury Architectural Midnight Navy Theme** (deep petroleum slates `#0A1120`, `#0F1A2E`, technical blueprint grid overlays, and vivid emerald green brand accents), complete with full **bilingual (Arabic RTL & English LTR)** support across all 17 pages.

---

## ✨ Features | المميزات الرئيسية

- **Bilingual Experience (عربي / English)**: Instant language switching with complete RTL and LTR typographic alignment.
- **Architectural Midnight Navy Identity**: Deep saturated navy and petroleum slates (distinctly NOT pure black) with blueprint drafting grid textures and ambient auras.
- **Projects Portfolio**: Live filtering by country (Saudi Arabia, Kuwait, Egypt/Heritage), sector, and engineering discipline, with detailed technical dossiers.
- **Engineering Disciplines**: Comprehensive catalogs for HVAC Chilled Water, Firefighting, Electrical MV/LV, Plumbing, BIM VDC, and Turnkey MEP.
- **BIM 3D/4D/5D Practice**: Interactive clash-detection and digital lifecycle visualization.
- **Executive Leadership**: Strictly verified engineering founders (**Eng. Tamim Badawi** & **Alaa Badawi**).
- **Executive Portal (`/admin`)**: Internal management dashboard for project inquiries and recruitment.
- **Interactive Forms**: Verified client consultation and career application modals connected to Next.js API endpoints.

## 🚀 Local Development | التشغيل المحلي

### Prerequisites
- Node.js 18.17+ or Node.js 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/alyketkat93-create/apec-website.git
cd apec-website

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application locally.

### Production Build
```bash
# Compile optimized production bundle
npm run build

# Start local production server
npm run start -- -p 3005
```
